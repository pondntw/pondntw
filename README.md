## 👨‍💻 About me

I build full-stack web apps with **TypeScript, Next.js, NestJS, and PostgreSQL** — handling everything from database schemas and business rules to the UI, testing, and deployment.

Before web development, I spent several years writing **game server scripts for FiveM (GTA V roleplay)** in Lua. Those scripts run on live servers with real players, which taught me early on to care about server-side validation, real-time updates, and keeping things configurable for non-developers.

- 🧱 **Philosophy:** I like putting business rules where they can't be bypassed — in the API or the database, not just the browser.
- 🧪 **Quality:** I write tests for the logic that matters (order rules, fees, access control).
- 🚀 **Showcase:** Every project below has a live demo you can try.
